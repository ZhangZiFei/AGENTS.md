# AGENTS.md

本仓库只用于维护 [`AGENTS.md`](./AGENTS.md)。该文件是 AI 编码代理（如 pi 等编码助手）的行为准则，包含纪律要求、工程规范、知识库规则和项目相关约定。

## 文件说明

| 文件 | 说明 |
|---|---|
| [`AGENTS.md`](./AGENTS.md) | 代理行为准则，是本仓库的核心产物 |
| [`LICENSE`](./LICENSE) | MIT 许可证 |
| `README.md` | 本说明文件 |

## AGENTS.md 结构概览

| 章节 | 主要内容 |
|---|---|
| 第一章 基础纪律 | 行为优先级、表达方式、副作用操作审批、变更流程 |
| 第二章 工程通用纪律 | 开发原则、BDD 测试要求、临时文件管理、知识库规范 |
| 第三章 当前项目相关纪律 | 具体项目的补充约定（当前为占位内容） |
| 能做什么 / 项目概览 / 项目结构 | 项目信息（当前为占位内容） |

## 使用方式

在其他项目中使用时，可以将 `AGENTS.md` 复制到目标项目根目录，或在目标项目中引用本仓库的文件内容。若目标项目有自己的约定，应在第三章及后续章节中补充，而不是直接修改通用章节。

## 维护说明

- 修改 `AGENTS.md` 前应先说明目标、范围与方案，并获得批准。
- 不在 `AGENTS.md` 中新增二级标题（见文件内的约束）。
- 本 README 只做概览，不复述 `AGENTS.md` 的具体条款，以免两处内容不一致。
